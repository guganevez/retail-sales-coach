## 📋 Sobre o Projeto

O **VendaCopiloto** é uma aplicação web que actua como coach de vendas inteligente para equipas B2B no sector da distribuição. Usando inteligência artificial, apoia o vendedor em campo com sugestões contextuais, análise de margem em tempo real e recomendações de produtos — tornando cada visita mais eficaz e lucrativa.

### Principais funcionalidades

- 🤖 **Sugestões com IA** — recomendações inteligentes durante o processo de venda, adaptadas ao cliente e contexto
- ⚡ **Pedidos rápidos** — registo ágil de encomendas directamente no cliente, sem fricção
- 📊 **Margem em tempo real** — visualização imediata do impacto financeiro de cada pedido
- 📈 **Dashboard de performance** — acompanhamento de métricas de vendas com gráficos interactivos
- 📱 **Interface responsiva** — optimizada para uso em tablet e telemóvel no terreno
